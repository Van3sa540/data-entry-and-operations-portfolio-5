Customer Data Cleaning & Verification

Project Overview
This project demonstrates how to organise, clean, and verify customer records using Google Sheets.

Tools Used
- Google Sheets
- Spreadsheet formulas

Tasks Performed
- Identified missing email addresses.
- Checked for duplicate customer IDs.
- Identified missing phone numbers.
- Checked email address formats.
- Created a data quality report.

Data Quality Results

| Issue Type | Records Affected | |---|---:|
| Missing Emails | 1 |
| Duplicate Customer IDs | 2 |
| Missing Phone Numbers | 1 |
| Invalid Email Formats | 1 |

Project Goal
To improve data accuracy, consistency, and reliability through structured data cleaning and verification.

Key Skills Demonstrated
- Data entry and organisation
- Data validation
- Duplicate detection
- Spreadsheet formulas
- Data quality reporting
